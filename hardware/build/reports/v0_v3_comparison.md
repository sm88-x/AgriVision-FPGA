# Sobel V0 vs V3 对比报告

> 口径:PS 基线 = 软件 Sobel 算法本身;PL E2E = DMA 收发全程(含 wait);FPS = 1000/均值;加速比 = PS 均值 / PL E2E 均值;正确性为逐像素对拍。

## 1. 板测性能(PYNQ-Z2,256x256 8bit 灰度)

| 图 | PS 均值 (ms) | PL E2E 均值 (ms) | PL FPS | 加速比 |
|---|---|---|---|---|
| clock | V0 40.96 / V3 41.41 | V0 6.129 / V3 0.976 | V0 163.1 / V3 1024.9 | V0 6.68x / V3 **42.44x** |
| plane | V0 42.05 / V3 43.57 | V0 6.129 / V3 0.981 | V0 163.2 / V3 1019.1 | V0 6.86x / V3 **44.40x** |
| airfield | V0 41.81 / V3 44.76 | V0 6.127 / V3 0.974 | V0 163.2 / V3 1026.8 | V0 6.82x / V3 **45.96x** |

- V3 的 PL E2E 极稳定(min–max 差 < 0.1 ms);V0 的 E2E 被核自身处理时间主导。

## 2. 核级指标(HLS csynth / cosim,100 MHz)

| 项 | V0 (sobel_axis) | V3 (sobel_v3) |
|---|---|---|
| Interval(cycles/帧) | 584726 | **65793** |
| 核处理时间 | 5.847 ms | **0.658 ms** |
| 主循环 II | 未流水 | **1** |
| cosim | Pass(interval avg 584214) | Pass(avg 65742) |
| **核加速比** | — | **8.89x** |

## 3. 资源与时序(全设计,Vivado 实现后)

| 项 | V0 | V3 |
|---|---|---|
| LUT | 2727 (5.13%) | 2729 (5.13%) |
| FF | 3472 (3.26%) | 3515 (3.30%) |
| BRAM | 3.5 tile | 3.5 tile |
| DSP | 0 | 0 |
| WNS / 时序 | 1.579 ns / met | 1.587 ns / met |

## 4. 结论

V3 流式重构以几乎不变的面积(资源增幅 < 1.5%),把核处理时间从 5.85 ms 压到 0.66 ms(8.89x),

   板端加速比从 ~6.8x 提升到 **42–46x**,PL 吞吐从 ~163 FPS 提升到 **~1020 FPS**。
