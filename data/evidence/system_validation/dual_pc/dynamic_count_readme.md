# 开发阶段 双机动态计数

## 结果

真实双电脑链路下完成 10 轮取粒：

- 初始数量：18

- 每轮取走：1 粒

- 轮数：10

- 最终数量：8

- 操作者现场确认：每一轮显示数量均正确

逐轮记录见 `dynamic_count_10rounds.csv`。

## 证据边界

该记录来自操作者现场目视确认。当天控制端曾重新启动，自动逐帧日志属于另一个运行会话，

无法与该组10轮操作一一对齐，因此本文件不填造逐轮 `detect_ms`、`fps` 或丢帧数。

同一双机链路另外保留有连续运行日志和静态逐帧 CSV：

- `data/evidence/network/network_frames.csv`

- `data/evidence/network/network_stability.csv`

这些日志证明网络帧率、检测耗时和链路稳定性，但不得冒充本组10轮取粒的逐轮延迟。

## 结论

动态计数功能由操作者确认通过；自动时间序列证据不完整。若验收要求每轮都有机器日志，

必须重新执行并保持同一个发送端、接收端和运行目录不重启。
