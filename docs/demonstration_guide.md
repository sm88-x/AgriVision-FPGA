# Qt 操作说明

构建与启动见[复现指南](reproduction.md)。载入已有文件用于复核，开始分析会运行当前算法；两者不能混作重新实测。

## 单图和批量

1. 选择单张图片或批量目录，再选择品种。单图可填写人工点数GT；整批不能共用一个GT。
2. 选择“本地回放”时全部在电脑处理；选择“板卡实时”时设置板卡IP和HTTP端口9001，先启动对应板端服务。
3. 勾选所需表型/分离结果并开始。板卡路径逐图返回FPGA图像、实际寄存器和DMA/RTT；检测、分离、表型仍使用电脑上的原图。
4. 单粒表型页按帧和目标查看；分离对比页切换固定分水岭与自适应结果。板端回执常驻左侧，切页后仍可核对。

关闭目标检测时，单图/批量只显示原图、可选FPGA预处理图和回执，不加载模型、不生成表型；板卡来源仍使用同一个HTTP端口。“生成对比”对话框也可勾选FPGA预处理。连接或校验失败时明确报错，不静默转成本机结果。

## 实时

板卡实时源使用TCP 9000服务；本地回放不占用板卡。网络摄像头源由另一台电脑通过AGF1发送帧，可勾选HTTP 9001转发FPGA，详见[双电脑运行手册](dual_pc_runbook.md)。同一板卡只能运行一个占用FPGA/DMA的处理服务。

## 查看、标定与导出

载入 `data/evidence/phenotyping/objects.json` 可查看已有五帧结果。列表与轮廓双向选择，滚轮缩放、拖动平移、双击打开大窗。当前帧导出包含可用图像、CSV和JSON；没有经过板卡时不伪造FPGA图。命令行 --export-all 逐帧导出整个已载入批次。

标定页支持同平面标尺的中心ROI比例标定。新增配置写入outputs/config；毫米换算必须确认机位，并满足图像尺寸、setup_id与目标ROI约束，否则保留px/px²。异常轮廓与UNRESOLVED原因保留，计数相等不代表分割正确。

耗时缺测为N/A；PL/DMA、往返与CPU耗时分别解释。软件截图不能代替实物展示或独立精度验收。
