# Qt操作说明

构建与启动见[复现指南](reproduction.md)。界面支持当前图像分析与历史结果复核，二者以日志和数据来源区分。

## 单图与批量分析

1. 在采集侧栏选择单张图片或批量目录，来源选本地回放。
2. 选择输入与品种；单图可填人工点数GT，未标注时不计算误差。
3. 勾选所需表型/分离结果并开始分析；检测、分离与测量在CPU执行。
4. 在单粒表型页切换帧，选择目标列表或图上轮廓查看指标；在分离对比页比较三种方法。

生成对比对话框同样只执行本机算法，板卡复选项已禁用。板卡像素处理使用实时模式，不向单图/批量脚本传入--board。

## 实时板卡与本地回放

实时板卡模式需要先启动对应板端帧服务并配置地址、端口、尺寸。当前帧的检测/分离/表型仍在CPU执行，FPGA只承担像素流预处理与统计。本地回放或mock不作为真板证据。停止后可按原配置重新开始；连接拒绝或超时应显示ERROR/OFFLINE并清空旧预览。

## 查看与导出

载入data/evidence/phenotyping/objects.json可查看已有结果。帧下拉切换输入，列表/轮廓双向选择；滚轮缩放、拖动平移、双击打开大窗。导出当前帧会产生原图、FPGA/处理图、标注图、表型图及CSV/JSON。命令行--export-all可逐帧导出整个已载入批次。

UNRESOLVED或轮廓异常保留具体原因；计数相同不等于实例分割正确。没有有效尺度标定时使用px与px²。耗时缺测为N/A，不把PL时间换算成系统帧率。软件截图只能证明界面和结果加载，不能代替实物展示。

启动缺DLL时按复现指南指定Qt运行库目录；不要切换到旧版本界面作为当前程序的替代入口。其他异常先查看运行日志及[验证范围](validation.md)。
