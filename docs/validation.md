# 验证结果与适用范围

## 验证层级

| 层级 | 依据 | 结论范围 |
|---|---|---|
| 算法参考 | 软件不变量、形态学独立实现、Golden数据 | 指定取整、饱和和边界语义的一致性 |
| 硬件构建 | HLS C仿真、综合、Vivado实现报告 | 源码可生成设计，资源与时序满足所列配置 |
| 软件链路 | TCP回环、连接拒绝、状态文件及Qt导出测试 | 协议、故障终止与结果关联 |
| 历史板测 | 原始CSV、固件指纹、配置和摘要 | 仅适用于对应固件和实验条件 |

推荐集成流水线保留72帧C仿真测试平台。数据证据覆盖14组/280行性能记录、应用回归与离线Golden；验证命令为 `python tools/verify.py`。构建与测试结果见 `tests/evidence/validation_summary.json` 和 `docs/evidence/rebuild_20261031`。

## 性能口径

PL驱动内端到端包含参数配置、DMA提交、PL处理及完成轮询，不包含相机采集、网络、模型与界面。HLS估计与Vivado实现资源分别标记；阶段功能不同的版本不能直接作为同功能加速对照。运行时旁路和参数切换不改变已经实现的LUT/FF/BRAM数量。

## 适用限制

系统面向背景受控的种子观察。Golden PASS不等于计数、实例分割或表型准确；计数相等也可能掩盖漏分与过分割。未有效标定时只报告px和px²。

新构建固件的现场验收状态与原固件的历史板测分开。原BD的DDR参数以及实现报告中的Warning/Advisory保留在证据中。不同机器的模型输出需要同时核对权重、输入、参数与依赖。

图像与权重的来源状态见 `data/provenance.csv`，来源未完整记录的素材不视为已取得独立再分发授权。

## 本轮严格核查修复

单图/批量界面原先会向不支持板端处理的comparison_runtime.py传入--board；现已禁用该选项并在统一入口提示支持范围，实时帧CPU分析也不再误传此参数。新增拒绝未支持参数的回归。

参数化Vivado脚本已修正默认IP/输出路径、wrapper名称、bit/hwh导出、已有工程保护及validate阶段；本轮实际生成bit/hwh/xsa，40帧C仿真通过，重建LUT3278/FF4184/BRAM3.5/DSP3，WNS +1.838 ns。归档历史指标单独保留。统一构建工具的相对--out现在从工程根解析，已由跨启动目录路径测试覆盖。

毫米标定文件标为无效时不能跨帧沿用比例。既有双PC动态计数记录缺少与每轮人工操作一一对应的延迟；网络帧龄也没有覆盖最后界面绘制，因此不作完整采集到显示延迟结论。双PC链路与PC到PYNQ链路的记录独立，不声称已经完成双PC再接板卡的现场总联调。
