## 案例 02 种子噪声与面积过滤

**问题与 Prompt 摘要**：用户比较 threshold=40/45，反馈马赛克、阴影误计数与种子轮廓不完整。

**模型建议**：模型建议保持较完整边缘，利用干扰轮廓面积较小的差异，提高 min_area 至 1000。

**纠错与决定**：先在原样例分离误检目标，再检查真实种子是否保留，避免仅增大边缘阈值导致漏边。

**验证证据**：用户后续明确反馈“8和9已被过滤”，但 2 号、4 号局部轮廓仍有误差。早期 seed 渲染图 Count=7。

**人工核验与证据边界**：该结论仅适用于旧七粒种子样例；最新42粒素材使用 min_area=100，不能套用旧阈值。

## 案例 03 区分计数正确与轮廓精度

**问题与 Prompt 摘要**：用户指出噪声已过滤，但 2 号轮廓不完整、4 号轮廓有小突起。

**模型建议**：模型建议对填充后的目标区域进行小范围开闭运算对比，而非对细边缘直接开运算。

**纠错与决定**：将边界修整作为对比预览，保留原始统计；计数改善不等于面积、周长已准确。

**验证证据**：当前应用仍采用外轮廓统计。本次未发现修整方案的定量准确率评测，报告不宣称轮廓误差已消除。

**人工核验与证据边界**：保留用户负面反馈与未闭合验证，避免把建议写成已验证创新。

## 案例 04 DMA 无输出打印的诊断

**问题与 Prompt 摘要**：用户提供已加载 Overlay 的代码，反馈搬运后续比较单元没有任何打印。

**模型建议**：模型指出 wait 可能无限等待，建议先保存 DMA 状态、逐步打印，核对 bit/hwh 配套关系。

**纠错与决定**：先定位发送/接收阻塞，再排查版本或帧边界；加载成功不能证明 bit/hwh 同构建。

**验证证据**：当前驱动用 IOC 完成标志轮询与超时，并从 HWH 动态获取地址。正式 CSV 证明后续配置完成过板测，不证明所有早期挂起已定位到唯一根因。

**人工核验与证据边界**：用户提供现场代码与现象，模型建议与当前实现可对照。

## 案例 05 64 字节尾部缺失与根因收敛

**问题与 Prompt 摘要**：用户反馈预填标记法显示最后64字节未写回，提出流水线少发64拍的判断。

**模型建议**：模型修正此前推断：DDR 未覆盖不等于 AXIS 少发同样拍数，建议数 TVALID/TREADY 握手并观察 TLAST。

**纠错与决定**：不盲目增加64次 drain，也不为 TLAST 添加固定周期延迟。将根因假设交由 RTL/ILA 证据验证。

**验证证据**：当前核心以 width+1 输出延迟保证每帧 width×height 输出，最后一个数据包置 TLAST。现有记录没有该次挂起的完整 ILA 波形，因此不声称唯一根因已证明。

**人工核验与证据边界**：案例展示模型承认不确定性并撤回过强判断；后续 cosim Pass 与板测只作为后续版本证据。
