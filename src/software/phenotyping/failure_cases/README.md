## 为什么会饱和

板端 V4 的形态学（`morph`）对二值结果做了固定半径的膨胀：

* 第 7 帧的种子约 **183 px** 宽 → ROI 内白色占比只有 0.32–0.58，形状测得出（六项指标正常）；

* 第 6 帧的种子只有约 **48 px** → 膨胀后整块糊成白色，轮廓其实就是那个 bbox，

  量出来的"面积 / 长 / 宽"等于框的尺寸，不是种子的形状。

也就是说：**越小越容易被膨胀吃掉**。这不是算法写错，是"固定膨胀半径 + 小目标"的物理限制。

因此规则里加了 `bbox_white_ratio ≥ 0.90 → BROKEN_CONTOUR`，把这些目标挑出来，

不让假数据混进 开发阶段 的分级统计。

## 对后续的建议

1. 要测小粒种子：把相机拉近一点（同一目标占更多像素），或者把板端 morph 的膨胀半径调小；

2. 目标之间留间隙、别铺到画面边缘（第 3、4 帧那类相挨/堆叠的画面会让 ROI 混入邻居的边缘）；

3. 开发阶段 做分级规则时，先按 `status` 过滤，只用 `OK` 的目标算分布。
